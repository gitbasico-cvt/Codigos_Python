# 🐍 Lógica de Programação com Python

## 📚 Sobre o projeto

Este repositório reúne materiais de estudo, exemplos de código e atividades práticas sobre **Lógica de Programação utilizando a linguagem Python**.

O objetivo é desenvolver o raciocínio lógico e ensinar os fundamentos da programação por meio de explicações didáticas, exemplos comentados e exercícios progressivos.

## 🎯 Objetivos de aprendizagem

- Compreender os fundamentos da lógica de programação.
- Aprender a utilizar variáveis e tipos de dados.
- Trabalhar com operadores aritméticos, relacionais e lógicos.
- Utilizar estruturas condicionais para tomar decisões.
- Repetir instruções com estruturas de repetição.
- Organizar informações utilizando listas.
- Criar funções para organizar e reutilizar código.
- Desenvolver pequenos programas para resolver problemas do cotidiano.
- Aprender a organizar projetos e acompanhar alterações utilizando Git e GitHub.

## 🧠 Conteúdos estudados

### 1. Fundamentos da programação
- Algoritmos e resolução de problemas.
- Entrada e saída de dados.
- Variáveis e atribuição de valores.
- Tipos de dados: `str`, `int`, `float` e `bool`.

### 2. Operadores
- Operadores aritméticos.
- Operadores relacionais.
- Operadores lógicos: `and`, `or` e `not`.

### 3. Estruturas condicionais
- `if`
- `if/else`
- `if/elif/else`
- Condições simples e compostas.

### 4. Estruturas de repetição
- Laço `while`.
- Repetição controlada por condições.
- Menus interativos.
- Controle de fluxo dos programas.

### 5. Listas e manipulação de dados
- Criação e acesso a listas.
- Adição de elementos.
- Atualização de elementos.
- Remoção de elementos.
- Verificação da existência de informações.

### 6. Estruturas de seleção
- `match/case`.
- Organização de opções em menus.
- Tratamento de opções inválidas.

### 7. Funções
- Definição e chamada de funções.
- Funções com e sem parâmetros.
- Funções com e sem retorno.
- Uso de `return`.
- Organização e reutilização de código.

### 8. Projeto prático — Estoque Fácil
Desenvolvimento de um sistema simples para praticar os conceitos estudados.

Funcionalidades propostas:
- Listar produtos cadastrados.
- Cadastrar novos produtos.
- Atualizar produtos existentes.
- Excluir produtos.
- Verificar se um produto existe.
- Contar a quantidade de produtos cadastrados.
- Organizar o programa utilizando funções.

### 9. Versionamento com Git e GitHub
- Criação e organização de repositórios.
- Registro de alterações com `commit`.
- Utilização de branches.
- Integração de alterações com `merge`.
- Documentação dos projetos com `README.md`.

## 🛠️ Tecnologias e ferramentas

- **Python 3** — linguagem de programação.
- **Visual Studio Code** — editor de código sugerido.
- **Git** — controle de versões.
- **GitHub** — hospedagem dos repositórios e colaboração.

## ▶️ Como executar os exemplos

1. Instale o Python 3 em seu computador.
2. Clone este repositório ou faça o download dos arquivos.
3. Abra a pasta do projeto no editor de código.
4. Abra o terminal na pasta onde está o arquivo Python.
5. Execute o programa com:

```bash
python nome_do_arquivo.py
```

Em alguns ambientes, pode ser necessário utilizar:

```bash
python3 nome_do_arquivo.py
```

Substitua `nome_do_arquivo.py` pelo nome do arquivo que deseja executar.
